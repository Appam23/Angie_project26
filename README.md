# Angie Project 26

This project is a professional business webpage for Angie Sumsion's care coordination and senior navigation services.

The website is designed to help families quickly understand:
- who Angie helps
- what services are offered
- available care support packages
- contact options and next steps

## Website Purpose

The page presents a clear, trust-focused profile for care coordination support, with a simple layout that works on mobile and desktop.

It highlights:
- Angie Sumsion's profile and service focus
- key care coordination offerings
- "I Do / I Don't" expectations
- pricing/package options
- a direct WhatsApp chat call-to-action

## Key Features

- Responsive hero section with profile image and service introduction
- Structured service content sections for easy reading
- Professional visual styling (cards, spacing, gradients, typography)
- Floating "Chat Now" WhatsApp button on the right side of the screen
- Server-side rendering with EJS templates

## Tech Stack

- Node.js
- Express
- EJS
- CSS

## Project Location

Main app folder:
- `care-coordination-site/`

Important files:
- `care-coordination-site/app.js` - Express app entry
- `Controller/controller.js` - main controller/data source
- `care-coordination-site/Views/home.ejs` - main page template
- `care-coordination-site/Public/css/style.css` - styling

## Run Locally

1. Open a terminal in `care-coordination-site/`
2. Install dependencies:
	- `pnpm install`
3. Start the app:
	- `pnpm start`
4. Open in browser:
	- `http://localhost:3000`

## Current Status

The webpage is live locally and includes WhatsApp-based chat access for quick contact.
